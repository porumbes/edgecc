# edgecc v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a working EDGE-to-Python transpiler that handles basic Map+Reduce Einsum expressions with tensor declarations, initialization, and pure Python loop-nest output.

**Architecture:** A classic compiler pipeline in C: Flex lexer → Bison parser → AST → semantic analysis → flat IR → Python code generation. Each stage is a separate .c/.h pair with a clean interface. CMake build system for cross-platform macOS/Linux.

**Tech Stack:** C (C99), Flex, Bison, CMake >= 3.15, Python 3 (target output + test driver)

#ifndef AST_H
#define AST_H

#include <stdlib.h>

/* Forward declarations */
typedef struct AstNode AstNode;
typedef struct TensorRef TensorRef;
typedef struct RankPair RankPair;
typedef struct LiteralData LiteralData;

/* ---- Enums ---- */

typedef enum {
    NODE_PROGRAM,
    NODE_DIM_DECL,
    NODE_TENSOR_DECL,
    NODE_INIT,
    NODE_EINSUM
} NodeType;

typedef enum {
    TYPE_INTEGER,
    TYPE_FLOAT,
    TYPE_BOOLEAN
} DataType;

typedef enum {
    OP_ADD,
    OP_SUB,
    OP_MUL,
    OP_MIN,
    OP_MAX,
    OP_AND,
    OP_OR
} OperatorType;

/* ---- Supporting structs ---- */

/* A (rank_name, dim_name) pair in a tensor declaration */
typedef struct RankPair {
    char *rank_name;
    char *dim_name;
} RankPair;

/* A tensor reference in an expression: Name[var1, var2, ...] */
typedef struct TensorRef {
    char *tensor_name;
    char **rank_vars;    /* array of rank variable names */
    int num_vars;
} TensorRef;

/* Nested literal data for init statements */
typedef struct LiteralData {
    int is_list;            /* 1 if this is a list of LiteralData, 0 if scalar */
    union {
        struct {
            struct LiteralData **items;
            int count;
        } list;
        struct {
            double float_val;
            int int_val;
            int bool_val;
            DataType type;
        } scalar;
    } data;
} LiteralData;

/* ---- AST Nodes ---- */

typedef struct {
    char *name;
    int size;
} DimDeclData;

typedef struct {
    char *name;
    RankPair *ranks;
    int num_ranks;
    DataType datatype;
    double empty_val;       /* stored as double; cast as needed */
} TensorDeclData;

typedef struct {
    char *tensor_name;
    LiteralData *data;
} InitData;

typedef struct {
    TensorRef output;
    TensorRef input1;
    TensorRef input2;
    OperatorType map_op;
    OperatorType reduce_op;
} EinsumData;

typedef struct {
    AstNode **statements;
    int count;
    int capacity;
} ProgramData;

struct AstNode {
    NodeType type;
    union {
        ProgramData program;
        DimDeclData dim_decl;
        TensorDeclData tensor_decl;
        InitData init;
        EinsumData einsum;
    } data;
};

/* ---- Constructors ---- */
AstNode *ast_program_new(void);
void ast_program_add(AstNode *program, AstNode *stmt);

AstNode *ast_dim_decl_new(char *name, int size);
AstNode *ast_tensor_decl_new(char *name, RankPair *ranks, int num_ranks,
                              DataType datatype, double empty_val);
AstNode *ast_init_new(char *tensor_name, LiteralData *data);
AstNode *ast_einsum_new(TensorRef output, TensorRef input1, TensorRef input2,
                         OperatorType map_op, OperatorType reduce_op);

TensorRef tensor_ref_new(char *name, char **rank_vars, int num_vars);

LiteralData *literal_scalar_int(int val);
LiteralData *literal_scalar_float(double val);
LiteralData *literal_scalar_bool(int val);
LiteralData *literal_list_new(LiteralData **items, int count);

/* ---- Destructors ---- */

/* ---- Utilities ---- */

- [ ] **Step 2: Create ast.c with implementations**

Create `src/ast.c`:
```c
#include "ast.h"
#include <stdio.h>
#include <string.h>

/* ---- Constructors ---- */

AstNode *ast_program_new(void) {
    AstNode *node = calloc(1, sizeof(AstNode));
    node->type = NODE_PROGRAM;
    node->data.program.capacity = 8;
    node->data.program.statements = calloc(8, sizeof(AstNode *));
    node->data.program.count = 0;
    return node;
}

void ast_program_add(AstNode *program, AstNode *stmt) {
    ProgramData *p = &program->data.program;
    if (p->count >= p->capacity) {
        p->capacity *= 2;
        p->statements = realloc(p->statements, p->capacity * sizeof(AstNode *));
    }
    p->statements[p->count++] = stmt;
}

AstNode *ast_dim_decl_new(char *name, int size) {
    AstNode *node = calloc(1, sizeof(AstNode));
    node->type = NODE_DIM_DECL;
    node->data.dim_decl.name = name;
    node->data.dim_decl.size = size;
    return node;
}

AstNode *ast_tensor_decl_new(char *name, RankPair *ranks, int num_ranks,
                              DataType datatype, double empty_val) {
    AstNode *node = calloc(1, sizeof(AstNode));
    node->type = NODE_TENSOR_DECL;
    node->data.tensor_decl.name = name;
    node->data.tensor_decl.ranks = ranks;
    node->data.tensor_decl.num_ranks = num_ranks;
    node->data.tensor_decl.datatype = datatype;
    node->data.tensor_decl.empty_val = empty_val;
    return node;
}

AstNode *ast_init_new(char *tensor_name, LiteralData *data) {
    AstNode *node = calloc(1, sizeof(AstNode));
    node->type = NODE_INIT;
    node->data.init.tensor_name = tensor_name;
    node->data.init.data = data;
    return node;
}

AstNode *ast_einsum_new(TensorRef output, TensorRef input1, TensorRef input2,
                         OperatorType map_op, OperatorType reduce_op) {
    AstNode *node = calloc(1, sizeof(AstNode));
    node->type = NODE_EINSUM;
    node->data.einsum.output = output;
    node->data.einsum.input1 = input1;
    node->data.einsum.input2 = input2;
    node->data.einsum.map_op = map_op;
    node->data.einsum.reduce_op = reduce_op;
    return node;
}

TensorRef tensor_ref_new(char *name, char **rank_vars, int num_vars) {
    TensorRef ref;
    ref.tensor_name = name;
    ref.rank_vars = rank_vars;
    ref.num_vars = num_vars;
    return ref;
}

LiteralData *literal_scalar_int(int val) {
    LiteralData *d = calloc(1, sizeof(LiteralData));
    d->is_list = 0;
    d->data.scalar.type = TYPE_INTEGER;
    d->data.scalar.int_val = val;
    d->data.scalar.float_val = (double)val;
    return d;
}

LiteralData *literal_scalar_float(double val) {
    LiteralData *d = calloc(1, sizeof(LiteralData));
    d->is_list = 0;
    d->data.scalar.type = TYPE_FLOAT;
    d->data.scalar.float_val = val;
    return d;
}

LiteralData *literal_scalar_bool(int val) {
    LiteralData *d = calloc(1, sizeof(LiteralData));
    d->is_list = 0;
    d->data.scalar.type = TYPE_BOOLEAN;
    d->data.scalar.bool_val = val;
    return d;
}

LiteralData *literal_list_new(LiteralData **items, int count) {
    LiteralData *d = calloc(1, sizeof(LiteralData));
    d->is_list = 1;
    d->data.list.items = items;
    d->data.list.count = count;
    return d;
}

/* ---- Destructors ---- */

void tensor_ref_free_contents(TensorRef *ref) {
    free(ref->tensor_name);
    for (int i = 0; i < ref->num_vars; i++) {
        free(ref->rank_vars[i]);
    }
    free(ref->rank_vars);
}

void literal_data_free(LiteralData *data) {
    if (!data) return;
    if (data->is_list) {
        for (int i = 0; i < data->data.list.count; i++) {
            literal_data_free(data->data.list.items[i]);
        }
        free(data->data.list.items);
    }
    free(data);
}

void ast_free(AstNode *node) {
    if (!node) return;
    switch (node->type) {
        case NODE_PROGRAM:
            for (int i = 0; i < node->data.program.count; i++) {
                ast_free(node->data.program.statements[i]);
            }
            free(node->data.program.statements);
            break;
        case NODE_DIM_DECL:
            free(node->data.dim_decl.name);
            break;
        case NODE_TENSOR_DECL:
            free(node->data.tensor_decl.name);
            for (int i = 0; i < node->data.tensor_decl.num_ranks; i++) {
                free(node->data.tensor_decl.ranks[i].rank_name);
                free(node->data.tensor_decl.ranks[i].dim_name);
            }
            free(node->data.tensor_decl.ranks);
            break;
        case NODE_INIT:
            free(node->data.init.tensor_name);
            literal_data_free(node->data.init.data);
            break;
        case NODE_EINSUM:
            tensor_ref_free_contents(&node->data.einsum.output);
            tensor_ref_free_contents(&node->data.einsum.input1);
            tensor_ref_free_contents(&node->data.einsum.input2);
            break;
    }
    free(node);
}

/* ---- Utilities ---- */

const char *datatype_to_str(DataType dt) {
    switch (dt) {
        case TYPE_INTEGER: return "integer";
        case TYPE_FLOAT:   return "float";
        case TYPE_BOOLEAN: return "boolean";
    }
    return "unknown";
}

const char *operator_to_str(OperatorType op) {
    switch (op) {
        case OP_ADD: return "add";
        case OP_SUB: return "sub";
        case OP_MUL: return "mul";
        case OP_MIN: return "min";
        case OP_MAX: return "max";
        case OP_AND: return "and";
        case OP_OR:  return "or";
    }
    return "unknown";
}

OperatorType operator_from_str(const char *name) {
    if (strcmp(name, "add") == 0) return OP_ADD;
    if (strcmp(name, "sub") == 0) return OP_SUB;
    if (strcmp(name, "mul") == 0) return OP_MUL;
    if (strcmp(name, "min") == 0) return OP_MIN;
    if (strcmp(name, "max") == 0) return OP_MAX;
    if (strcmp(name, "and") == 0) return OP_AND;
    if (strcmp(name, "or") == 0)  return OP_OR;
    return -1; /* invalid */
}

/* Flex interface */
typedef struct yy_buffer_state *YY_BUFFER_STATE;
extern int yylex(void);
extern YY_BUFFER_STATE yy_scan_string(const char *str);
extern void yy_delete_buffer(YY_BUFFER_STATE buf);

TEST(test_dim_keyword) {
    YY_BUFFER_STATE buf = yy_scan_string("dim");
    ASSERT_INT_EQ(TOK_DIM, yylex());
    yy_delete_buffer(buf);
}

TEST(test_tensor_keyword) {
    YY_BUFFER_STATE buf = yy_scan_string("tensor");
    ASSERT_INT_EQ(TOK_TENSOR, yylex());
    yy_delete_buffer(buf);
}

TEST(test_identifier) {
    YY_BUFFER_STATE buf = yy_scan_string("myVar");
    ASSERT_INT_EQ(TOK_IDENT, yylex());
    ASSERT_STR_EQ("myVar", yylval.str_val);
    free(yylval.str_val);
    yy_delete_buffer(buf);
}

TEST(test_int_literal) {
    YY_BUFFER_STATE buf = yy_scan_string("42");
    ASSERT_INT_EQ(TOK_INT_LIT, yylex());
    ASSERT_INT_EQ(42, yylval.int_val);
    yy_delete_buffer(buf);

    YY_BUFFER_STATE buf = yy_scan_string("3.14");
    ASSERT_INT_EQ(TOK_FLOAT_LIT, yylex());
    ASSERT_TRUE(yylval.float_val > 3.13 && yylval.float_val < 3.15);
    yy_delete_buffer(buf);
}

TEST(test_double_colon) {
    YY_BUFFER_STATE buf = yy_scan_string("::");
    ASSERT_INT_EQ(TOK_DOUBLE_COLON, yylex());
    yy_delete_buffer(buf);
}

TEST(test_full_token_sequence) {
    YY_BUFFER_STATE buf = yy_scan_string("dim M = 4;");
    ASSERT_INT_EQ(TOK_DIM, yylex());
    ASSERT_INT_EQ(TOK_IDENT, yylex());
    ASSERT_STR_EQ("M", yylval.str_val);
    free(yylval.str_val);
    ASSERT_INT_EQ('=', yylex());
    ASSERT_INT_EQ(TOK_INT_LIT, yylex());
    ASSERT_INT_EQ(4, yylval.int_val);
    ASSERT_INT_EQ(';', yylex());
    yy_delete_buffer(buf);
}

TEST(test_comment_skipped) {

"inf"               { yylval.float_val = 1.0/0.0; return TOK_FLOAT_LIT; }

"::"                { return TOK_DOUBLE_COLON; }

[0-9]+\.[0-9]+      { yylval.float_val = atof(yytext); return TOK_FLOAT_LIT; }
[0-9]+              { yylval.int_val = atoi(yytext); return TOK_INT_LIT; }

[a-zA-Z_][a-zA-Z0-9_]* { yylval.str_val = strdup(yytext); return TOK_IDENT; }

[=\.\,\;\:\[\]\(\)]  { return yytext[0]; }

.                   { fprintf(stderr, "lexer error: unexpected character '%c'\n", yytext[0]); }

%%

#include "semantic.h"
#include <stdio.h>
#include <string.h>

static void add_error(SemanticResult *res, const char *fmt, ...) {
    if (res->error_count >= res->error_capacity) {
        res->error_capacity = res->error_capacity ? res->error_capacity * 2 : 8;
        res->errors = realloc(res->errors, res->error_capacity * sizeof(char *));
    }
    char buf[256];
    va_list args;
    va_start(args, fmt);
    vsnprintf(buf, sizeof(buf), fmt, args);
    va_end(args);
    res->errors[res->error_count++] = strdup(buf);
}

static int find_dim(SymbolTable *st, const char *name) {
    for (int i = 0; i < st->num_dims; i++) {
        if (strcmp(st->dims[i].name, name) == 0) return st->dims[i].size;
    }
    return -1;
}

static TensorEntry *find_tensor(SymbolTable *st, const char *name) {
    for (int i = 0; i < st->num_tensors; i++) {
        if (strcmp(st->tensors[i].name, name) == 0) return &st->tensors[i];
    }
    return NULL;
}

static void analyze_dim_decl(AstNode *node, SemanticResult *res) {
    SymbolTable *st = res->symtab;
    DimDeclData *dd = &node->data.dim_decl;

    if (find_dim(st, dd->name) >= 0) {
        add_error(res, "duplicate dimension '%s'", dd->name);
        return;
    }
    st->dims[st->num_dims].name = strdup(dd->name);
    st->dims[st->num_dims].size = dd->size;
    st->num_dims++;
}

static void analyze_tensor_decl(AstNode *node, SemanticResult *res) {
    SymbolTable *st = res->symtab;
    TensorDeclData *td = &node->data.tensor_decl;

    if (find_tensor(st, td->name)) {
        add_error(res, "duplicate tensor '%s'", td->name);
        return;
    }

    TensorEntry *te = &st->tensors[st->num_tensors];
    te->name = strdup(td->name);
    te->ranks = td->ranks;
    te->num_ranks = td->num_ranks;
    te->datatype = td->datatype;
    te->empty_val = td->empty_val;

    for (int i = 0; i < td->num_ranks; i++) {
        int size = find_dim(st, td->ranks[i].dim_name);
        if (size < 0) {
            add_error(res, "undeclared dimension '%s' in tensor '%s'",
                      td->ranks[i].dim_name, td->name);
            return;
        }
        te->dim_sizes[i] = size;
    }
    st->num_tensors++;
}

static void check_init_shape(LiteralData *data, int *expected_dims,
                              int ndims, int depth, SemanticResult *res,
                              const char *tensor_name) {
    if (depth >= ndims) {
        if (data->is_list) {
            add_error(res, "init data for '%s' is too deeply nested", tensor_name);
        }
        return;
    }
    if (!data->is_list) {
        add_error(res, "init data for '%s' has insufficient nesting at depth %d",
                  tensor_name, depth);
        return;
    }
    if (data->data.list.count != expected_dims[depth]) {
        add_error(res, "init data for '%s' has %d elements at depth %d, expected %d",
                  tensor_name, data->data.list.count, depth, expected_dims[depth]);
        return;
    }
    for (int i = 0; i < data->data.list.count; i++) {
        check_init_shape(data->data.list.items[i], expected_dims, ndims,
                        depth + 1, res, tensor_name);
    }
}

static void analyze_init(AstNode *node, SemanticResult *res) {
    SymbolTable *st = res->symtab;
    InitData *init = &node->data.init;

    TensorEntry *te = find_tensor(st, init->tensor_name);
    if (!te) {
        add_error(res, "init references undeclared tensor '%s'", init->tensor_name);
        return;
    }

    check_init_shape(init->data, te->dim_sizes, te->num_ranks, 0, res, init->tensor_name);
}

/* Resolve a rank variable: find what dimension size it maps to via the tensor declaration.
   rank_var is the variable name used in the expression (e.g., "m").
   ref is the tensor reference in the expression (e.g., A[k,m]).
   position is the index of rank_var within ref's rank_vars list. */
static int resolve_index_size(const char *rank_var, TensorRef *ref, int position,
                               SymbolTable *st, SemanticResult *res) {
    TensorEntry *te = find_tensor(st, ref->tensor_name);
    if (!te) {
        add_error(res, "undeclared tensor '%s'", ref->tensor_name);
        return -1;
    }
    if (position >= te->num_ranks) {
        add_error(res, "tensor '%s' has %d ranks but expression uses %d indices",
                  ref->tensor_name, te->num_ranks, ref->num_vars);
        return -1;
    }
    return te->dim_sizes[position];
}

static void analyze_einsum(AstNode *node, SemanticResult *res) {
    SymbolTable *st = res->symtab;
    EinsumData *es = &node->data.einsum;

    /* Check tensors exist */
    if (!find_tensor(st, es->output.tensor_name)) {
        add_error(res, "undeclared tensor '%s'", es->output.tensor_name);
        return;
    }
    if (!find_tensor(st, es->input1.tensor_name)) {
        add_error(res, "undeclared tensor '%s'", es->input1.tensor_name);
        return;
    }
    if (!find_tensor(st, es->input2.tensor_name)) {
        add_error(res, "undeclared tensor '%s'", es->input2.tensor_name);
        return;
    }

    /* Collect all unique index variables and their sizes.
       An index is "free" if it appears in the output, "reduction" otherwise. */
    typedef struct { char *name; int size; int in_output; } IdxInfo;
    IdxInfo all_indices[MAX_INDICES];
    int num_all = 0;

    /* Helper: add or check an index */
    #define ADD_OR_CHECK_INDEX(var, sz, is_out) do { \
        int found = 0; \
        for (int _i = 0; _i < num_all; _i++) { \
            if (strcmp(all_indices[_i].name, var) == 0) { \
                if (all_indices[_i].size != sz) { \
                    add_error(res, "index '%s' has conflicting sizes %d and %d", \
                              var, all_indices[_i].size, sz); \
                } \
                if (is_out) all_indices[_i].in_output = 1; \
                found = 1; \
                break; \
            } \
        } \
        if (!found) { \
            all_indices[num_all].name = var; \
            all_indices[num_all].size = sz; \
            all_indices[num_all].in_output = is_out; \
            num_all++; \
        } \
    } while(0)

    /* Process output indices */
    for (int i = 0; i < es->output.num_vars; i++) {
        int sz = resolve_index_size(es->output.rank_vars[i], &es->output, i, st, res);
        if (sz < 0) return;
        ADD_OR_CHECK_INDEX(es->output.rank_vars[i], sz, 1);
    }

    /* Process input1 indices */
    for (int i = 0; i < es->input1.num_vars; i++) {
        int sz = resolve_index_size(es->input1.rank_vars[i], &es->input1, i, st, res);
        if (sz < 0) return;
        ADD_OR_CHECK_INDEX(es->input1.rank_vars[i], sz, 0);
    }

    /* Process input2 indices */
    for (int i = 0; i < es->input2.num_vars; i++) {
        int sz = resolve_index_size(es->input2.rank_vars[i], &es->input2, i, st, res);
        if (sz < 0) return;
        ADD_OR_CHECK_INDEX(es->input2.rank_vars[i], sz, 0);
    }

    #undef ADD_OR_CHECK_INDEX

    /* Classify into free and reduction */
    for (int i = 0; i < num_all; i++) {
        if (all_indices[i].in_output) {
            IndexEntry *ie = &st->free_indices[st->num_free_indices++];
            ie->name = strdup(all_indices[i].name);
            ie->size = all_indices[i].size;
            ie->is_free = 1;
        } else {
            IndexEntry *ie = &st->reduction_indices[st->num_reduction_indices++];
            ie->name = strdup(all_indices[i].name);
            ie->size = all_indices[i].size;
            ie->is_free = 0;
        }
    }
}

SemanticResult semantic_analyze(AstNode *program) {
    SemanticResult res = {0};
    res.symtab = calloc(1, sizeof(SymbolTable));

    for (int i = 0; i < program->data.program.count; i++) {
        AstNode *stmt = program->data.program.statements[i];
        switch (stmt->type) {
            case NODE_DIM_DECL:    analyze_dim_decl(stmt, &res); break;
            case NODE_TENSOR_DECL: analyze_tensor_decl(stmt, &res); break;
            case NODE_INIT:        analyze_init(stmt, &res); break;
            case NODE_EINSUM:      analyze_einsum(stmt, &res); break;
            default: break;
        }
    }
    return res;
}

void semantic_result_free(SemanticResult *res) {
    if (res->symtab) {
        for (int i = 0; i < res->symtab->num_dims; i++)
            free(res->symtab->dims[i].name);
        for (int i = 0; i < res->symtab->num_tensors; i++)
            free(res->symtab->tensors[i].name);
        for (int i = 0; i < res->symtab->num_free_indices; i++)
            free(res->symtab->free_indices[i].name);
        for (int i = 0; i < res->symtab->num_reduction_indices; i++)
            free(res->symtab->reduction_indices[i].name);
        free(res->symtab);
    }
    for (int i = 0; i < res->error_count; i++)
        free(res->errors[i]);
    free(res->errors);
}

#include "ir.h"
#include <string.h>

static void ir_emit(IRProgram *ir, IRInstr instr) {
    if (ir->count >= ir->capacity) {
        ir->capacity = ir->capacity ? ir->capacity * 2 : 32;
        ir->instrs = realloc(ir->instrs, ir->capacity * sizeof(IRInstr));
    }
    ir->instrs[ir->count++] = instr;
}

static char **dup_str_array(char **src, int count) {
    char **dst = calloc(count, sizeof(char *));
    for (int i = 0; i < count; i++) dst[i] = strdup(src[i]);
    return dst;
}

static void emit_dim_defs(IRProgram *ir, SymbolTable *st) {
    for (int i = 0; i < st->num_dims; i++) {
        IRInstr instr = { .type = IR_DIM_DEF };
        instr.data.dim_def.name = strdup(st->dims[i].name);
        instr.data.dim_def.size = st->dims[i].size;
        ir_emit(ir, instr);
    }
}

static void emit_tensor_allocs(IRProgram *ir, AstNode *program, SymbolTable *st) {
    for (int i = 0; i < program->data.program.count; i++) {
        AstNode *stmt = program->data.program.statements[i];
        if (stmt->type != NODE_TENSOR_DECL) continue;

        TensorEntry *te = NULL;
        for (int j = 0; j < st->num_tensors; j++) {
            if (strcmp(st->tensors[j].name, stmt->data.tensor_decl.name) == 0) {
                te = &st->tensors[j];
                break;
            }
        }
        if (!te) continue;

        IRInstr instr = { .type = IR_TENSOR_ALLOC };
        instr.data.tensor_alloc.name = strdup(te->name);
        instr.data.tensor_alloc.ndims = te->num_ranks;
        memcpy(instr.data.tensor_alloc.dim_sizes, te->dim_sizes,
               te->num_ranks * sizeof(int));
        instr.data.tensor_alloc.empty_val = te->empty_val;
        ir_emit(ir, instr);
    }
}

static void emit_tensor_inits(IRProgram *ir, AstNode *program) {
    for (int i = 0; i < program->data.program.count; i++) {
        AstNode *stmt = program->data.program.statements[i];
        if (stmt->type != NODE_INIT) continue;

        IRInstr instr = { .type = IR_TENSOR_INIT };
        instr.data.tensor_init.name = strdup(stmt->data.init.tensor_name);
        instr.data.tensor_init.data = stmt->data.init.data; /* borrowed */
        ir_emit(ir, instr);
    }
}

static void emit_einsum(IRProgram *ir, EinsumData *es, SymbolTable *st) {
    int reg = 0;

    /* Emit free index loops (output indices) */
    for (int i = 0; i < st->num_free_indices; i++) {
        IRInstr instr = { .type = IR_LOOP_BEGIN };
        instr.data.loop_begin.index_var = strdup(st->free_indices[i].name);
        instr.data.loop_begin.range = st->free_indices[i].size;
        ir_emit(ir, instr);
    }

    /* Emit reduction index loops */
    for (int i = 0; i < st->num_reduction_indices; i++) {
        IRInstr instr = { .type = IR_LOOP_BEGIN };
        instr.data.loop_begin.index_var = strdup(st->reduction_indices[i].name);
        instr.data.loop_begin.range = st->reduction_indices[i].size;
        ir_emit(ir, instr);
    }

    /* LOAD input1 -> reg 0 */
    {
        IRInstr instr = { .type = IR_LOAD };
        instr.data.load.reg = reg;
        instr.data.load.tensor_name = strdup(es->input1.tensor_name);
        instr.data.load.coords = dup_str_array(es->input1.rank_vars, es->input1.num_vars);
        instr.data.load.ncoords = es->input1.num_vars;
        ir_emit(ir, instr);
    }

    /* LOAD input2 -> reg 1 */
    {
        IRInstr instr = { .type = IR_LOAD };
        instr.data.load.reg = reg + 1;
        instr.data.load.tensor_name = strdup(es->input2.tensor_name);
        instr.data.load.coords = dup_str_array(es->input2.rank_vars, es->input2.num_vars);
        instr.data.load.ncoords = es->input2.num_vars;
        ir_emit(ir, instr);
    }

    /* MAP reg0, reg1 -> reg2 */
    {
        IRInstr instr = { .type = IR_MAP };
        instr.data.map.dst_reg = reg + 2;
        instr.data.map.op = es->map_op;
        instr.data.map.src_reg1 = reg;
        instr.data.map.src_reg2 = reg + 1;
        ir_emit(ir, instr);
    }

    /* REDUCE: acc(output[coords]) with mapped value -> reg3 */
    {
        IRInstr instr = { .type = IR_REDUCE };
        instr.data.reduce.dst_reg = reg + 3;
        instr.data.reduce.op = es->reduce_op;
        instr.data.reduce.src_reg = reg + 2;
        instr.data.reduce.acc_reg = -1; /* signals: use output tensor location */
        ir_emit(ir, instr);
    }

    /* STORE reg3 -> output */
    {
        IRInstr instr = { .type = IR_STORE };
        instr.data.store.tensor_name = strdup(es->output.tensor_name);
        instr.data.store.coords = dup_str_array(es->output.rank_vars, es->output.num_vars);
        instr.data.store.ncoords = es->output.num_vars;
        instr.data.store.src_reg = reg + 3;
        ir_emit(ir, instr);
    }

    /* Close loops (reduction first, then free — reverse order) */
    for (int i = 0; i < st->num_reduction_indices; i++) {
        IRInstr instr = { .type = IR_LOOP_END };
        ir_emit(ir, instr);
    }
    for (int i = 0; i < st->num_free_indices; i++) {
        IRInstr instr = { .type = IR_LOOP_END };
        ir_emit(ir, instr);
    }
}

IRProgram *ir_lower(AstNode *program, SymbolTable *symtab) {
    IRProgram *ir = calloc(1, sizeof(IRProgram));

    emit_dim_defs(ir, symtab);
    emit_tensor_allocs(ir, program, symtab);
    emit_tensor_inits(ir, program);

    /* Find and emit the einsum */
    for (int i = 0; i < program->data.program.count; i++) {
        AstNode *stmt = program->data.program.statements[i];
        if (stmt->type == NODE_EINSUM) {
            emit_einsum(ir, &stmt->data.einsum, symtab);
        }
    }

    return ir;
}

void ir_free(IRProgram *ir) {
    if (!ir) return;
    for (int i = 0; i < ir->count; i++) {
        IRInstr *instr = &ir->instrs[i];
        switch (instr->type) {
            case IR_DIM_DEF:
                free(instr->data.dim_def.name);
                break;
            case IR_TENSOR_ALLOC:
                free(instr->data.tensor_alloc.name);
                break;
            case IR_TENSOR_INIT:
                free(instr->data.tensor_init.name);
                break;
            case IR_LOOP_BEGIN:
                free(instr->data.loop_begin.index_var);
                break;
            case IR_LOAD:
                free(instr->data.load.tensor_name);
                for (int j = 0; j < instr->data.load.ncoords; j++)
                    free(instr->data.load.coords[j]);
                free(instr->data.load.coords);
                break;
            case IR_STORE:
                free(instr->data.store.tensor_name);
                for (int j = 0; j < instr->data.store.ncoords; j++)
                    free(instr->data.store.coords[j]);
                free(instr->data.store.coords);
                break;
            case IR_MAP:
            case IR_REDUCE:
            case IR_LOOP_END:
                break;
        }
    }
    free(ir->instrs);
    free(ir);
}

static void cb_ensure(CodeBuf *cb, int extra) {

    }
}

static void cb_append(CodeBuf *cb, const char *s) {
    int slen = strlen(s);
    cb_ensure(cb, slen + 1);
    memcpy(cb->buf + cb->len, s, slen);
    cb->len += slen;
    cb->buf[cb->len] = '\0';
}

static void cb_indent(CodeBuf *cb) {
    for (int i = 0; i < cb->indent; i++) cb_append(cb, "    ");
}

static void cb_printf(CodeBuf *cb, const char *fmt, ...) {
    char tmp[1024];
    va_list args;
    va_start(args, fmt);
    vsnprintf(tmp, sizeof(tmp), fmt, args);
    va_end(args);
    cb_append(cb, tmp);
}

static void emit_literal_data(CodeBuf *cb, LiteralData *data) {
    if (!data->is_list) {
        switch (data->data.scalar.type) {
            case TYPE_INTEGER:
                cb_printf(cb, "%d", data->data.scalar.int_val);
                break;
            case TYPE_FLOAT:
                cb_printf(cb, "%g", data->data.scalar.float_val);
                break;
            case TYPE_BOOLEAN:
                cb_append(cb, data->data.scalar.bool_val ? "True" : "False");
                break;
        }
        return;
    }
    cb_append(cb, "[");
    for (int i = 0; i < data->data.list.count; i++) {
        if (i > 0) cb_append(cb, ", ");
        emit_literal_data(cb, data->data.list.items[i]);
    }
    cb_append(cb, "]");
}

static void emit_tensor_alloc(CodeBuf *cb, IRTensorAlloc *alloc) {
    /* Generate nested list comprehension, e.g.:
       Z = [[0.0] * N for _ in range(M)] */
    cb_indent(cb);
    cb_printf(cb, "%s = ", alloc->name);

    if (alloc->ndims == 0) {
        cb_printf(cb, "%g", alloc->empty_val);
    } else if (alloc->ndims == 1) {
        cb_printf(cb, "[%g] * %d", alloc->empty_val, alloc->dim_sizes[0]);
    } else {
        /* For 2D: [[empty] * cols for _ in range(rows)] */
        /* General: nest from outermost to innermost */
        for (int d = 0; d < alloc->ndims - 1; d++) {
            cb_append(cb, "[");
        }
        cb_printf(cb, "[%g] * %d", alloc->empty_val, alloc->dim_sizes[alloc->ndims - 1]);
        for (int d = alloc->ndims - 2; d >= 0; d--) {
            cb_printf(cb, " for _ in range(%d)]", alloc->dim_sizes[d]);
        }
    }
    cb_append(cb, "\n");
}

static const char *py_op_symbol(OperatorType op) {
    switch (op) {
        case OP_ADD: return "+";
        case OP_SUB: return "-";
        case OP_MUL: return "*";
        case OP_AND: return "and";
        case OP_OR:  return "or";
        default: return "?";
    }
}

static int op_is_function(OperatorType op) {
    return op == OP_MIN || op == OP_MAX;
}

static const char *py_op_func(OperatorType op) {
    switch (op) {
        case OP_MIN: return "min";
        case OP_MAX: return "max";
        default: return "?";
    }
}

static void emit_coords(CodeBuf *cb, char **coords, int ncoords) {
    for (int i = 0; i < ncoords; i++) {
        cb_printf(cb, "[%s]", coords[i]);
    }
}

/* Track the output tensor name and coords for the REDUCE instruction,
   which needs to reference the current accumulator in the output. */
static char *current_output_tensor = NULL;
static char **current_output_coords = NULL;
static int current_output_ncoords = 0;

char *codegen_python(IRProgram *ir) {
    CodeBuf cb;
    cb_init(&cb);

    current_output_tensor = NULL;

    for (int i = 0; i < ir->count; i++) {
        IRInstr *instr = &ir->instrs[i];
        switch (instr->type) {
            case IR_DIM_DEF:
                cb_indent(&cb);
                cb_printf(&cb, "%s = %d\n", instr->data.dim_def.name,
                          instr->data.dim_def.size);
                break;

            case IR_TENSOR_ALLOC:
                emit_tensor_alloc(&cb, &instr->data.tensor_alloc);
                break;

            case IR_TENSOR_INIT:
                cb_indent(&cb);
                cb_printf(&cb, "%s = ", instr->data.tensor_init.name);
                emit_literal_data(&cb, instr->data.tensor_init.data);
                cb_append(&cb, "\n");
                break;

            case IR_LOOP_BEGIN:
                cb_indent(&cb);
                cb_printf(&cb, "for %s in range(%s):\n",
                          instr->data.loop_begin.index_var,
                          /* Find the dim name for this range */
                          instr->data.loop_begin.index_var);
                /* We need the dim name, not the var name. Search backwards
                   for a DIM_DEF with matching size. */
                /* Actually, let's emit range(SIZE) as a number for correctness,
                   but use the dim name if we can find it. */
                break;

            case IR_LOOP_END:
                cb.indent--;
                break;

            case IR_LOAD:
                /* No explicit Python line needed — we inline in MAP */
                break;

            case IR_MAP:
                /* Handled together with REDUCE */
                break;

            case IR_REDUCE:
                /* Combine LOAD + MAP + REDUCE into one Python line */
                break;

            case IR_STORE:
                break;
        }

        /* After LOOP_BEGIN, increase indent */
        if (instr->type == IR_LOOP_BEGIN) {
            cb.indent++;
        }
    }

    /* That approach is too complex. Let me redo: instead of handling each IR
       instruction individually, let's scan for the compute block pattern
       (LOAD, LOAD, MAP, REDUCE, STORE) and emit a single combined line. */

    /* Reset and redo */
    free(cb.buf);
    cb_init(&cb);

    cb_append(&cb, "# Generated by edgecc\n\n");

    for (int i = 0; i < ir->count; i++) {
        IRInstr *instr = &ir->instrs[i];
        switch (instr->type) {
            case IR_DIM_DEF:
                cb_printf(&cb, "%s = %d\n", instr->data.dim_def.name,
                          instr->data.dim_def.size);
                break;

            case IR_TENSOR_ALLOC:
                emit_tensor_alloc(&cb, &instr->data.tensor_alloc);
                break;

            case IR_TENSOR_INIT:
                cb_printf(&cb, "%s = ", instr->data.tensor_init.name);
                emit_literal_data(&cb, instr->data.tensor_init.data);
                cb_append(&cb, "\n");
                break;

            case IR_LOOP_BEGIN: {
                cb_append(&cb, "\n");
                cb_indent(&cb);
                /* Find dim name for range — search DIM_DEFs for matching size */
                const char *dim_name = NULL;
                for (int j = 0; j < i; j++) {
                    if (ir->instrs[j].type == IR_DIM_DEF &&
                        ir->instrs[j].data.dim_def.size == instr->data.loop_begin.range) {
                        dim_name = ir->instrs[j].data.dim_def.name;
                    }
                }
                if (dim_name) {
                    cb_printf(&cb, "for %s in range(%s):\n",
                              instr->data.loop_begin.index_var, dim_name);
                } else {
                    cb_printf(&cb, "for %s in range(%d):\n",
                              instr->data.loop_begin.index_var,
                              instr->data.loop_begin.range);
                }
                cb.indent++;
                break;
            }

            case IR_LOOP_END:
                cb.indent--;
                break;

            case IR_LOAD:
                /* Skip — inlined in the STORE step */
                break;

            case IR_MAP:
                /* Skip — inlined in the STORE step */
                break;

            case IR_REDUCE:
                /* Skip — inlined in the STORE step */
                break;

            case IR_STORE: {
                /* Look back to find the LOAD, LOAD, MAP, REDUCE sequence */
                IRInstr *load1 = NULL, *load2 = NULL;
                IRInstr *map = NULL, *reduce = NULL;
                for (int j = i - 1; j >= 0 && j >= i - 4; j--) {
                    if (ir->instrs[j].type == IR_LOAD && !load2) load2 = &ir->instrs[j];
                    else if (ir->instrs[j].type == IR_LOAD) load1 = &ir->instrs[j];
                    if (ir->instrs[j].type == IR_MAP) map = &ir->instrs[j];
                    if (ir->instrs[j].type == IR_REDUCE) reduce = &ir->instrs[j];
                }

                cb_indent(&cb);
                /* Emit: output[coords] = reduce_op(output[coords], map_op(input1[coords], input2[coords])) */
                /* e.g.: Z[m][n] = Z[m][n] + A[k][m] * B[k][n] */

                /* LHS */
                cb_printf(&cb, "%s", instr->data.store.tensor_name);
                emit_coords(&cb, instr->data.store.coords, instr->data.store.ncoords);

                cb_append(&cb, " = ");

                /* RHS: reduce(acc, map(a, b)) */
                if (reduce && op_is_function(reduce->data.reduce.op)) {
                    cb_printf(&cb, "%s(", py_op_func(reduce->data.reduce.op));
                    cb_printf(&cb, "%s", instr->data.store.tensor_name);
                    emit_coords(&cb, instr->data.store.coords, instr->data.store.ncoords);
                    cb_append(&cb, ", ");
                } else {
                    cb_printf(&cb, "%s", instr->data.store.tensor_name);
                    emit_coords(&cb, instr->data.store.coords, instr->data.store.ncoords);
                    cb_printf(&cb, " %s ", py_op_symbol(reduce->data.reduce.op));
                }

                /* map(a, b) */
                if (map && op_is_function(map->data.map.op)) {
                    cb_printf(&cb, "%s(", py_op_func(map->data.map.op));
                    cb_printf(&cb, "%s", load1->data.load.tensor_name);
                    emit_coords(&cb, load1->data.load.coords, load1->data.load.ncoords);
                    cb_append(&cb, ", ");
                    cb_printf(&cb, "%s", load2->data.load.tensor_name);
                    emit_coords(&cb, load2->data.load.coords, load2->data.load.ncoords);
                    cb_append(&cb, ")");
                } else {
                    cb_printf(&cb, "%s", load1->data.load.tensor_name);
                    emit_coords(&cb, load1->data.load.coords, load1->data.load.ncoords);
                    cb_printf(&cb, " %s ", py_op_symbol(map->data.map.op));
                    cb_printf(&cb, "%s", load2->data.load.tensor_name);
                    emit_coords(&cb, load2->data.load.coords, load2->data.load.ncoords);
                }

                if (reduce && op_is_function(reduce->data.reduce.op)) {
                    cb_append(&cb, ")");
                }

                cb_append(&cb, "\n");
                break;
            }
        }
    }

    /* Emit print for output tensor (find the STORE instruction's tensor) */
    for (int i = ir->count - 1; i >= 0; i--) {
        if (ir->instrs[i].type == IR_STORE) {
            cb_printf(&cb, "\nprint(%s)\n", ir->instrs[i].data.store.tensor_name);
            break;
        }
    }

    return cb.buf;
}
```

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "ast.h"
#include "semantic.h"
#include "ir.h"
#include "codegen.h"

/* Flex/Bison interface */
extern int yyparse(void);
extern AstNode *parse_result;
extern FILE *yyin;

int main(int argc, char *argv[]) {
    if (argc < 2) {
        fprintf(stderr, "Usage: edgecc <input.edge> [-o output.py]\n");
        return 1;
    }

    const char *input_file = argv[1];
    const char *output_file = "output.py";

    for (int i = 2; i < argc; i++) {
        if (strcmp(argv[i], "-o") == 0 && i + 1 < argc) {
            output_file = argv[++i];
        }
    }

    /* Open input file */
    FILE *in = fopen(input_file, "r");
    if (!in) {
        fprintf(stderr, "error: cannot open '%s'\n", input_file);
        return 1;
    }
    yyin = in;

    /* Parse */
    if (yyparse() != 0) {
        fprintf(stderr, "error: parsing failed\n");
        fclose(in);
        return 1;
    }
    fclose(in);

    if (!parse_result) {
        fprintf(stderr, "error: no AST produced\n");
        return 1;
    }

    /* Semantic analysis */
    SemanticResult sem = semantic_analyze(parse_result);
    if (sem.error_count > 0) {
        for (int i = 0; i < sem.error_count; i++) {
            fprintf(stderr, "error: %s\n", sem.errors[i]);
        }
        semantic_result_free(&sem);
        ast_free(parse_result);
        return 1;
    }

    /* IR lowering */
    IRProgram *ir = ir_lower(parse_result, sem.symtab);

    /* Code generation */
    char *code = codegen_python(ir);

    /* Write output */
    FILE *out = fopen(output_file, "w");
    if (!out) {
        fprintf(stderr, "error: cannot open '%s' for writing\n", output_file);
        free(code);
        ir_free(ir);
        semantic_result_free(&sem);
        ast_free(parse_result);
        return 1;
    }
    fputs(code, out);
    fclose(out);

    fprintf(stderr, "edgecc: %s -> %s\n", input_file, output_file);

    /* Cleanup */
    free(code);
    ir_free(ir);
    semantic_result_free(&sem);
    ast_free(parse_result);
    return 0;
}

#!/usr/bin/env python3
"""End-to-end test driver for edgecc."""
import os
import subprocess
import sys
import tempfile

def run_test(test_dir, edgecc_bin):
    name = os.path.basename(test_dir)
    input_file = os.path.join(test_dir, "input.edge")
    expected_output = os.path.join(test_dir, "expected_output.txt")

    if not os.path.exists(input_file) or not os.path.exists(expected_output):
        return None  # skip

    with tempfile.NamedTemporaryFile(suffix=".py", delete=False) as tmp:
        tmp_py = tmp.name

    try:
        # Compile
        result = subprocess.run(
            [edgecc_bin, input_file, "-o", tmp_py],
            capture_output=True, text=True, timeout=10
        )
        if result.returncode != 0:
            print(f"  FAIL {name}: edgecc failed: {result.stderr.strip()}")
            return False

        # Run generated Python
        result = subprocess.run(
            [sys.executable, tmp_py],
            capture_output=True, text=True, timeout=10
        )
        if result.returncode != 0:
            print(f"  FAIL {name}: python failed: {result.stderr.strip()}")
            return False

        # Compare output
        with open(expected_output) as f:
            expected = f.read().strip()
        actual = result.stdout.strip()

        if actual == expected:
            print(f"  PASS {name}")
            return True
        else:
            print(f"  FAIL {name}: expected '{expected}', got '{actual}'")
            return False
    finally:
        os.unlink(tmp_py)


def main():
    script_dir = os.path.dirname(os.path.abspath(__file__))
    edgecc_bin = sys.argv[1] if len(sys.argv) > 1 else "edgecc"

    passed = 0
    failed = 0
    for entry in sorted(os.listdir(script_dir)):
        test_dir = os.path.join(script_dir, entry)
        if not os.path.isdir(test_dir):
            continue
        result = run_test(test_dir, edgecc_bin)
        if result is None:
            continue
        if result:
            passed += 1
        else:
            failed += 1

    print(f"\n{passed}/{passed + failed} e2e tests passed")
    sys.exit(1 if failed > 0 else 0)


if __name__ == "__main__":
    main()

## What is edgecc?

edgecc is a compiler/transpiler for the EDGE language, a declarative index-driven language that extends Einstein summation (Einsum) notation with alternative semirings. EDGE expressions describe tensor computations using three core operations: Map (binary op on paired elements), Reduce (aggregation), and Populate (fiber-level, not yet implemented). The compiler targets Python as its output — generating pure nested for-loops with scalar operations.

## Build

```bash
mkdir -p build && cd build
cmake ..
make
```

Requires: C compiler (C99), CMake >= 3.15, Flex, Bison, Python 3.

## Run

```bash
./build/edgecc input.edge -o output.py
python3 output.py
```

## Test

```bash
cd build && ctest --output-on-failure
```

This runs:
- Unit tests per pipeline stage: `test_lexer`, `test_parser`, `test_semantic`, `test_ir`, `test_codegen`
- End-to-end tests: `tests/e2e/run_e2e.py` (compiles .edge, runs generated Python, compares output)
- Negative tests: `tests/negative/run_negative.py` (invalid programs that must produce specific errors)

To run a single unit test: `./build/test_lexer`

## Architecture

Pipeline: `.edge source → Lexer (Flex) → Parser (Bison) → AST → Semantic Analysis → IR → Python Codegen → .py`

- `src/lexer.l` — Flex tokenizer
- `src/parser.y` — Bison grammar, builds AST via constructors in ast.h
- `src/ast.h/c` — AST node types (tagged union structs), constructors, destructors
- `src/semantic.h/c` — Validates index consistency, resolves dimensions, classifies indices as free vs reduction. Produces a SymbolTable.
- `src/ir.h/c` — Flat VM-style instruction list (LOOP_BEGIN, LOAD, MAP, REDUCE, STORE, LOOP_END). Lowered from AST + SymbolTable.
- `src/codegen.h/c` — Walks IR sequentially, emits Python with indentation tracking. Inlines LOAD+MAP+REDUCE+STORE into single Python assignment lines.

## EDGE Syntax (v1)

```
dim M = 4;
tensor Z[R=M, C=N] : float, empty = 0.0;
init A = [[1, 2], [3, 4]];
Z[m,n] = A[k,m] . B[k,n] :: map(mul) reduce(add);
```

Rank variables in expressions bind to declared rank names by position. Indices in both inputs but not the output are reduction indices (inner loops). Built-in operators: add, sub, mul, min, max, and, or.
